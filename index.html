What is a computer?

A computer is an electronic device that stores and processes data in binary, following instructions called a program. It is hardware (physical parts) plus software (instructions).

1. Input

Takes in data and instructions.

2. Processing

Works with the data.

3. Output

Puts out information.

Computer = Hardware + Software

Hardware

The physical parts you can touch, built from circuits and transistors.

Software

The instructions that tell the hardware what to do. You cannot touch them.

Think of a music box: the box is hardware, the song is software. A computer is very fast but not clever. It must be told exactly what to do, step by step.

The CPU

The Central Processing Unit is the brain of the computer. It does arithmetic and logic, controls other hardware, and repeats the instruction cycle non-stop.

What is the CPU?

The Central Processing Unit is a small chip: the brain of the computer. It runs programs, does calculations, makes decisions and controls every other part.

What is inside it?

ALU calculates. CU directs the work. Registers hold the data in use right now. Cache keeps frequent data close.

How does it work?

It repeats one loop for as long as a program runs: fetch an instruction from RAM, decode it, execute it, store the result in RAM.

Memory

Primary storage has four types. The closer to the CPU, the faster it is and the less it holds.

What is RAM?

Random Access Memory is the short-term workspace of the computer. It holds the programs and data being used right now.

Why is it needed?

The CPU fetches instructions from RAM and sends results back to it. RAM is much faster than a disk.

It is temporary

RAM is emptied when the power goes off. Save your files to storage (SSD, HDD) to keep them.

Octal and hexadecimal

Binary is perfect for machines but hard for people: long and easy to misread. Octal (base 8) and hexadecimal (base 16) are short ways to write binary.

Why do we need them?

Shorter

One octal digit replaces 3 bits. One hex digit replaces 4 bits, so one byte (8 bits) is just 2 hex digits.

Fewer mistakes

1101011010101111 is easy to misread. D6AF is the same number, and much easier.

Easy to convert

8 = 2³ and 16 = 2⁴. That is why converting between binary, octal and hex is just grouping bits.

Same number, four ways. Type a number.

Where you meet them

Web colors

#FF0000 is red: FF red, 00 green, 00 blue. Each color is one byte, written as 2 hex digits.

Network cards

A MAC address like 00:1A:2B:3C:4D:5E is 6 bytes written in hex.

Memory and errors

Memory addresses and error codes are shown in hex. The prefix 0x means “hexadecimal”: 0x1F = 31.

Linux rights

chmod 755 is octal: each digit is 3 bits, r w x. You will see it in Unit 2.

Method 1. Decimal to octal or hexadecimal: divide by 8 or 16

It is the same method as decimal to binary, but you divide by 8 (octal) or 16 (hexadecimal). Keep dividing the quotient until it is 0, then read the remainders from bottom to top. In hex, a remainder from 10 to 15 is written A to F.

Method 2. Octal or hexadecimal to decimal: multiply by powers

Give each digit its position from the right: 0, 1, 2… Multiply each digit by 8 or 16 to the power of its position, then add everything. Example: 64₈ = 6 × 8¹ + 4 × 8⁰ = 48 + 4 = 52.

Method 3. Binary to octal or hexadecimal: group the bits

Group the bits from the right: groups of 3 for octal, groups of 4 for hexadecimal. Add zeros on the left if the last group is short. Then write the value of each group.

And back: octal or hexadecimal to binary

Replace each octal digit by its 3 bits, or each hex digit by its 4 bits.

Welcome back, it’s Nuo! In Unit 1 you met hardware and software. Now meet the most important software of all: the operating system.

What is an operating system?

An OS is the software that manages hardware and software resources and provides services for computer programs.

Manages resources

Shares the CPU, memory and storage between programs.

Provides a user interface

Gives you a way to talk to the computer: windows and icons, or typed commands.

Security and multitasking

Protects your files with accounts and passwords, and runs many programs at once.

Think of the OS as a school principal. Teachers (programs) need classrooms (memory), time slots (CPU time) and keys (permissions). The principal shares them out so everyone can work.

Files and folders

The OS organizes everything you save into files and folders (also called directories).

File

Holds data: a document, an image, a song, a program.

Each file has a size (10 KB, 5 MB…), a type (.txt, .docx, .exe…) and rights (r, w, x).

Folder (directory)

A container that groups files, and other folders, in a tree.

Each folder has a size (1 GB, 500 MB…) and rights (r, w, x).

The command line interface (CLI)

The CLI lets you talk to the OS by typing text commands instead of clicking.

GUI

Graphical User Interface: windows, icons, menus and the mouse.

CLI

Command Line Interface: you type a command and press Enter.

Why learn the CLI?

Faster

One line like mkdir G1 G2 G3 G4 creates four folders at once.

Troubleshooting

Powerful tools to find and fix problems, even when the GUI is broken.

Automation

Save commands in a script and run them again and again.

Read the prompt

Windows: Command Prompt

C:\NBS>

You are on drive C, inside the folder NBS. Open it: Windows key, type cmd, press Enter.

Linux: Terminal

student@nbs:~/NBS$

User student on computer nbs, inside NBS in the home folder (~). Open it with Ctrl + Alt + T on Ubuntu.

    Managing files and folders

    You can manage files in two ways: with the mouse in a GUI, or with commands in a CLI.
